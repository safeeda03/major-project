# PoshanAI mobile application

This is the native React Native application for Anganwadi workers, supervisors, and parents. It shares the Express API in `../backend`; `../frontend` remains an optional browser dashboard.

## What is ready

- Native role-based navigation for worker, supervisor, and parent users.
- Persistent authentication with secure local session storage.
- Native screens for beneficiaries, health, nutrition, vaccinations, attendance, reports, chatbot, and centre mapping. Beneficiary IDs are now generated by the API when a child is added.
- A profile screen with a safe sign-out flow.
- One centralized API address in `src/config.js`.

## Run it

1. Start MongoDB, seed the backend users, and start the API as described in [the project setup guide](../SETUP_GUIDE.md).
2. In this directory, install JavaScript dependencies:

   ```powershell
   npm install
   ```

3. Configure `src/config.js`:

   - Keep `10.0.2.2` for the Android emulator.
   - Use your development computer's LAN address for a physical Android device.

4. Restore the Android Gradle wrapper if it is absent in this imported project, then run the app:

   ```powershell
   npx react-native@0.72.17 init PoshanAIBootstrap --directory $env:TEMP\PoshanAIBootstrap --skip-install
   Copy-Item $env:TEMP\PoshanAIBootstrap\android\* .\android -Recurse -Force
   npm run android
   ```

The original Android directory was only a partial scaffold (it did not include a Gradle wrapper, native application class, activity, or Android resources). The command above supplies the matching official React Native native shell while retaining the application source in `src/`.
